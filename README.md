# DonOriginal3DMusic3

音楽を3D FLACに変換するWindows用ソフトです。  
複数の曲をまとめて変換できます。

## ダウンロード

配布ファイルは **Releases** に置きます。  
ZIPを解凍して `DonOriginal3DMusic3.exe` を起動してください。

## 使い方

1. 「曲を追加」で変換する曲を選ぶ
2. 保存先を決める
3. 「選択した曲をまとめて3D変換」を押す

FLAC以外の音楽ファイルも読み込めます。出力はFLAC（48kHz / 24bit）です。

## 注意

- Windows 10 / 11（64bit）向けです。
- `assets` と `tools` は必要なデータなので消さないでください。
- 曲数やPCの性能によって変換に時間がかかります。
- 元の音楽ファイルはそのまま残ります。
- 音の聞こえ方はイヤホンやヘッドホンによって変わります。
- 自分が利用できる音楽ファイルを使ってください。
