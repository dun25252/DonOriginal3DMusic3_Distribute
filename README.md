# DonOriginal3DMusic3

音楽ファイルを3D FLACへ変換するWindows用ソフトです。  
複数の曲をまとめて変換できます。

## 使い方

1. ZIPを解凍して「DonOriginal3DMusic3.exe」を起動
2. 「曲を追加」から音楽を選択
3. 保存先を指定して3D変換を開始

変換した曲は、保存先の **「3D変換先」** フォルダーに入ります。  
ファイル名は **「曲名_v1.0.flac」**、音声形式はFLAC（48kHz / 24bit）です。

## 注意

- Windows 10 / 11（64bit）用です。
- 「assets」「tools」は変換に使うファイルです。消さないでください。
- 変換には曲の長さに応じて時間がかかります。
- 音の聞こえ方は使うイヤホン・ヘッドホンによって異なります。
- 元の音楽ファイルは変更しません。
